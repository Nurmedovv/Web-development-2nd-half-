Информационная система «Автобаза»

Диспетчеризация заявок на грузоперевозки: маршруты, водители и автомобили в единой базе данных

О системе

Система предназначена для диспетчеризации заявок на грузоперевозки. Диспетчер распределяет заявки между водителями, за каждыми из которых закреплён свой автомобиль. На рейс назначается автомобиль, находящийся в исправном состоянии и характеристики которого соответствуют заявке: тип кузова и грузоподъёмность.

Приложение построено по паттерну «фронт-контроллер»: единый сервлет-диспетчер принимает все запросы и передаёт их отдельным контроллерам. Страницы генерируются серверной шаблонизацией Thymeleaf, данные хранятся в базе autobase (Microsoft SQL Server) и доступаются через JPA.

Java Servlet Thymeleaf JPA · EclipseLink MS SQL Server Log4j2 Jetty
